Recap

Da Aula 7 aos scripts de hoje, interativos

Scripts Que Ainda Não Conversam

A Aula 7 explicou shebang, como rodar um script com ./script.sh e variáveis. Mas todo script que escrevemos até agora roda sempre a MESMA sequência fixa de comandos, sem depender de nada que a pessoa que está usando digite. Hoje isso muda: scripts que perguntam algo e fazem conta com a resposta.

Dois conceitos novos de hoje

read, pra capturar o que o usuário digita numa variável, e operações aritméticas, pra fazer conta de verdade com essas variáveis — já que, como vimos na Aula 7, toda variável de shell é só texto, sem tipo.

Entrada de Dados: read

Lendo o que o usuário digita

read: Capturando uma Resposta

saudacao.sh
#!/bin/bash

echo "Qual é o seu nome?"
read nome

echo "Olá, $nome!"

O script PARA e espera

Quando o shell chega na linha read nome, a execução do script congela até a pessoa digitar algo e apertar Enter. O que foi digitado vai direto pra dentro da variável nome — sem $, igual na Aula 7 quando a variável é CRIADA.

read -p: Pergunta e Leitura na Mesma Linha

saudacao.sh (mais enxuto)
#!/bin/bash

read -p "Qual é o seu nome? " nome
echo "Olá, $nome!"

Duas linhas viram uma

-p (de "prompt") junta o echo da pergunta com o read da resposta numa linha só. Repare o espaço depois do ? dentro das aspas — sem ele, o que a pessoa digitar gruda direto na pergunta na tela.

read com Mais de uma Variável

apresentacao.sh
#!/bin/bash

read -p "Digite seu nome e sua idade: " nome idade

echo "$nome tem $idade anos"

read separa pelo espaço

Se a pessoa digitar Ana 17, o read quebra a resposta pelos espaços: a primeira palavra (Ana) vai pra nome, a segunda (17) vai pra idade.

Operações Aritméticas

Fazendo conta de verdade com $(( ))

O Problema: + Dentro de Aspas Não Soma

errado.sh
#!/bin/bash

a=3
b=5

echo "$a + $b"
O que aparece na tela
Você esperavaO que realmente imprime
83 + 5

Variável de shell é sempre texto (Aula 7)

Dentro de aspas, $a e $b são trocados pelo TEXTO que guardam — o + no meio é só mais um caractere da frase, não uma operação matemática.

$(( expressao )): Agora é Conta de Verdade

certo.sh
#!/bin/bash

a=3
b=5

echo $((a + b))

Dentro de $(( )) o shell entende que é matemática

Repare que nem precisa do $ antes de a e b AQUI DENTRO (funciona igual se colocar, mas não é obrigatório) — o $((...)) já avisa o shell que o que está dentro é uma expressão aritmética, não texto.

Bash Só Calcula com Inteiros

echo $((7 / 2))     # 3, e nao 3.5
echo $((7 % 2))     # 1 -- o resto da divisao

Pra casas decimais, existe o bc

O $(( )) arredonda qualquer divisão pro inteiro mais próximo de zero — sem decimais. Quando a conta PRECISA de casas decimais, usamos o bc (basic calculator), passando a expressão por pipe: echo "7 / 2" | bc -l devolve 3.50000000000000000000.

Juntando Tudo

Dois scripts práticos: soma e IMC

Script Somador

somador.sh
#!/bin/bash

read -p "Digite o primeiro numero: " n1
read -p "Digite o segundo numero: " n2

soma=$((n1 + n2))

echo "A soma e: $soma"

A conta pode morar numa variável

soma=$((n1 + n2)) guarda o RESULTADO da conta numa variável nova, do mesmo jeito que qualquer outra atribuição da Aula 7 — depois é só usar $soma como qualquer variável de texto.

Exercício: Calculadora de IMC

Na Aula 4, imc.c calculava o IMC em C. Hoje refazemos a MESMA conta em Shell Script — e como IMC quase sempre tem casas decimais, essa é a hora de usar o bc.

imc.sh
#!/bin/bash

read -p "Digite seu peso (kg): " peso
read -p "Digite sua altura (m): " altura

imc=$(echo "$peso / ($altura * $altura)" | bc -l)

echo "Seu IMC e: $imc"

Por que não dava pra usar $(( ))

Se trocasse bc -l por $(( )) aqui, a divisão inteira cortaria toda casa decimal do IMC — um erro silencioso, sem mensagem nenhuma, só um resultado errado.

Exercícios: read e Aritmética

O que entregar

Salve cada script como um arquivo .sh separado, com chmod +x (Aula 7) antes de rodar.

  1. Crie operacoes.sh: pede dois números com read -p e mostra, numa linha cada, a soma, a subtração, a multiplicação e a divisão INTEIRA dos dois ($(( ))).
  2. Crie resto.sh: pede um número e mostra o resto da divisão dele por 2 (%) — sem decidir nada ainda, só mostre o valor do resto (0 ou 1).
  3. Reescreva a lógica do bissexto.c (Aula 4) em bissexto.sh: peça um ano e mostre o resto da divisão dele por 4 — novamente, só mostrando o resto, sem decidir se é bissexto (isso vem na Aula 9).
  4. Crie retangulo.sh: pede base e altura de um retângulo e calcula a área com $(( )) e, separadamente, com bc -l — compare os dois resultados e explique por que podem ser diferentes.
  5. Desafio: crie celsius.sh, que pede uma temperatura em Celsius e converte pra Fahrenheit usando bc -l (fórmula: F = C * 9/5 + 32).
