Slide 02

Variáveis e Tipos de Dados

int idade = 16;
float altura = 1.72;
char inicial = 'W';

printf("Idade: %d anos\n", idade);
printf("Altura: %.2f m\n", altura);
printf("Inicial: %c\n", inicial);

Relembrando: int guarda números inteiros, float guarda números com casas decimais e char guarda um único caractere. Cada tipo ocupa um espaço diferente na memória e usa um especificador de formato diferente no printf (%d, %f, %c).

Slide 03

Entrada e Saída: scanf e printf

int nota1, nota2;

printf("Digite a primeira nota: ");
scanf("%d", &nota1);

printf("Digite a segunda nota: ");
scanf("%d", &nota2);

printf("Media: %d\n", (nota1 + nota2) / 2);

Não esqueça do &

O & antes da variável no scanf diz pro programa onde na memória guardar o valor digitado. Esquecer o & é um dos erros mais comuns em C.

Slide 04

Operadores Aritméticos, Relacionais e Lógicos

int a = 7, b = 2;

printf("%d\n", a % b);   // resto da divisao: 1
printf("%d\n", a > b);   // relacional: 1 (verdadeiro)

if (a > b && b > 0) {
    printf("a eh maior que b, e b eh positivo\n");
}

O % devolve o resto da divisão inteira — muito usado pra saber se um número é par ou ímpar. Operadores relacionais (>, <, ==...) resultam em verdadeiro ou falso, e o && combina duas condições: só é verdadeiro se as duas forem verdadeiras.

Slide 05

Estruturas de Decisão: if/else e switch

int opcao = 2;

if (opcao == 1) {
    printf("Iniciar jogo\n");
} else if (opcao == 2) {
    printf("Configuracoes\n");
} else {
    printf("Opcao invalida\n");
}

switch (opcao) {
    case 1:
        printf("Iniciar jogo\n");
        break;
    case 2:
        printf("Configuracoes\n");
        break;
    default:
        printf("Opcao invalida\n");
}

Regra de ouro do switch

Não esqueça o break em cada case — sem ele, a execução continua para o próximo case de baixo, mesmo que a condição não bata.

Slide 06

Strings: Guardando Textos em C

E se eu quiser guardar uma palavra?

Até agora, char guarda só um caractere. Mas e se eu quiser guardar um nome, um apelido, uma frase inteira? Pra isso existe a string — um vetor de char.

char texto[20] = "Six Seven";

printf("Seu apelido de gamer eh: %s\n", texto);

Repare no %s, o especificador usado especificamente para strings — diferente do %d (inteiro), %f (decimal) ou %c (um único caractere). O número entre colchetes ([20]) reserva espaço pra até 20 caracteres.

Slide 07

Por Dentro de uma String

Como "Six Seven" fica guardado na memória
Índice0123456789
CaractereSix Seven\0

O caractere invisível \0

C guarda automaticamente um \0 (terminador nulo) logo depois do último caractere real. É assim que funções como printf sabem onde a string termina — sem ele, o programa continuaria lendo lixo de memória adiante.

Por Que Repetir?

Quando fazer a mesma coisa várias vezes

Slide 08

O Problema do Código Repetido

printf("%d\n", 1);
printf("%d\n", 2);
printf("%d\n", 3);
printf("%d\n", 4);
printf("%d\n", 5);

E se fossem 1000 números?

Copiar e colar a mesma linha centenas de vezes é impraticável, difícil de manter e um convite a erros. Precisamos de uma estrutura que repita um bloco de código automaticamente.

Slide 09

A Ideia por Trás dos Laços

Estrutura genérica de repetição
flowchart TD A([Início]) --> B{Condição é verdadeira?} B -- Sim --> C[Executa o bloco de código] C --> B B -- Não --> D([Continua o programa])
Enquanto a condição for verdadeira, o bloco se repete. Quando ela vira falsa, o programa segue em frente.

O Laço While

Repetindo enquanto uma condição for verdadeira

Slide 10

Sintaxe do While

while (condição) {
    // bloco executado enquanto
    // a condição for verdadeira
}

Teste no início

A condição é avaliada antes de cada execução do bloco. Se ela já começar falsa, o bloco nunca é executado nem uma vez.

Slide 11

Exemplo: Farmando Aura com o While

int aura = 0;

while (aura < 100) {
    printf("+20 de aura!\n");
    aura = aura + 20;
}

printf("Aura maxima atingida: %d\n", aura);

Repare nas três partes essenciais: a variável aura inicializada antes do laço, a condição (aura < 100) que controla quantas vezes ele roda, e o aura = aura + 20 que atualiza a variável dentro do bloco — sem isso, a condição nunca mudaria e o jogador ficaria preso nesse laço pra sempre.

Slide 13

Cuidado: Laço Infinito

int aura = 0;

while (aura < 100) {
    printf("+20 de aura!\n");
    // esqueceu de atualizar a aura!
}

Laço Infinito

Sem o aura = aura + 20;, a variável aura nunca muda — a condição aura < 100 nunca fica falsa e o jogador fica preso nesse laço pra sempre, sem nunca terminar de farmar aura. Sempre pergunte: "o que dentro do laço muda a condição?"

Desafios

Praticando com o While

  1. Escreva um programa em C que use while para imprimir os números de 1 a 10.
  2. Modifique o programa anterior para imprimir apenas os números pares entre 1 e 10.
  3. Faça uma contagem regressiva de 10 até 1 usando while (dica: agora o incremento precisa diminuir o valor).
  4. Peça ao usuário um número N com scanf e imprima todos os números de 1 até N.
  5. Desafio: o trecho int i = 0; while (i < 5) { printf("%d", i); } tem um laço infinito. Identifique o que falta e reescreva o código corrigido.
