Sintaxe do laço aninhado em C

Slide 04

Sintaxe: for dentro de for

Um laço aninhado é um laço inteiro (for, while ou do-while) escrito dentro do corpo de outro laço. Quem está por fora é o laço externo; quem está por dentro é o laço interno — e o interno pode ser qualquer um dos três tipos que você já conhece.

treino.c
for (int serie = 1; serie <= 3; serie++) {          // laco EXTERNO
    printf("Serie %d:\n", serie);
    for (int rep = 1; rep <= 12; rep++) {           // laco INTERNO
        printf("  Repeticao %d\n", rep);
    }
}

O limite pode variar

Repara que o laço interno não vai até um número fixo — vai até linha. O limite de um laço interno pode depender do valor do laço externo. É essa ideia que desenha o padrão.

Cuidado: Nomes das Variáveis

Por que i (fora) e j (dentro), e não os dois i?

Slide 09

O Bug Clássico do Laço Aninhado

bug_classico.c
int i;
for (i = 1; i <= 3; i++) {
    for (i = 1; i <= 5; i++) {   // BUG: reusa a MESMA variavel i!
        printf("*");
    }
    printf("\n");
}
// ao sair do laco interno, i ja vale 6 -> o laco externo
// nunca mais volta -> so imprime 1 linha, nao 3
corrigido.c
for (int i = 1; i <= 3; i++) {          // i cuida do laco externo
    for (int j = 1; j <= 5; j++) {      // j cuida do laco interno, sozinho
        printf("*");
    }
    printf("\n");
}

Convenção: i pro laço mais de fora, j pro próximo, k se precisar de um terceiro. Evita esse bug e deixa o código mais fácil de ler.

Misturando Tipos de Laço

for por fora, while por dentro — e vice-versa

Slide 10

Combinando for e while

Não existe regra de "só for com for". Cada laço aninhado escolhe seu tipo pelo mesmo critério da Aula 6: número de repetições conhecido → for; depende de uma condição em tempo de execução → while/do-while.

for (int rodada = 1; rodada <= 3; rodada++) {        // FOR: 3 rodadas, numero conhecido
    int palpite;
    printf("Rodada %d - digite 1 a 10: ", rodada);
    scanf("%d", &palpite);

    while (palpite < 1 || palpite > 10) {             // WHILE: repete ate ser valido
        printf("Invalido! Tente de novo: ");
        scanf("%d", &palpite);
    }
}

Sua ferramenta contra bugs

Hoje vimos a ORDEM de execução com um teste de mesa simples — essa é a ferramenta mais poderosa que vocês têm pra caçar bugs em laços aninhados mais complexos: sempre que o resultado não bater, façam o teste de mesa e sigam o rastro, linha por linha.

Desafios

  1. Desafio 1 — Tabuada sob medida: peça um número N ao usuário e imprima a tabuada de N (de N×1 até N×10) usando dois for.
  2. Desafio 2 — Grade de crafting: imprima uma grade 3×3 de asteriscos (tipo uma mesa de crafting) e depois adapte pra ler do usuário quantas linhas e colunas a grade deve ter.
  3. Desafio 3 — Pirâmide invertida: imprima um triângulo de asteriscos que começa com 5 e diminui até 1 por linha — o contrário do exemplo que vimos em aula.

Dica de ouro

Antes de escrever qualquer for, desenhe no papel como a saída deve ficar. Aí é só perguntar: quantas linhas eu preciso (laço externo)? E em cada linha, quantas repetições (laço interno)?
