O problema do copiar e colar

Lá na Aula 1, o problema do código duplicado te fez conhecer o while: em vez de repetir um comando várias vezes seguidas, um laço repete o MESMO trecho sozinho. Só que existe outro tipo de repetição que o laço não resolve: o mesmo trecho copiado em partes BEM DIFERENTES do programa.

printf("========================\n");
printf("   RELATORIO DE VENDAS\n");
printf("========================\n");

// ... um monte de codigo no meio ...

printf("========================\n");
printf("   RELATORIO DE ESTOQUE\n");
printf("========================\n");

// ... e de novo, mais pra frente ...

printf("========================\n");
printf("   RELATORIO FINAL\n");
printf("========================\n");
Slide 04

DRY: Don't Repeat Yourself

O risco de copiar e colar

Se um dia você precisar trocar o "=" por "-" nesse separador, vai ter que lembrar de mudar em TODOS os lugares onde copiou. Esquecer um é um bug silencioso — e ninguém avisa.

Slide 05

Bloco de código nomeado e reutilizável

Analogia: combo de jogo

Você grava uma sequência de botões (o combo) uma única vez. Depois é só apertar o atalho pra executar a sequência inteira — quantas vezes quiser.

Na programação

Você escreve o bloco de código (a função) uma única vez, com um nome. Depois só chama esse nome pra executar o bloco — de qualquer lugar do programa.

Você já usa uma função

Desde o semestre passado você escreve int main() { ... }. main é, tecnicamente, a SUA primeira função! Ela só é especial porque é o ponto onde o programa começa a rodar.

saudacao.c
#include <stdio.h>

// Função sem parâmetros e sem retorno
void saudar() {
    printf("Bem-vindo ao programa!\n");
    printf("Vamos começar.\n");
}

int main() {
    saudar();   // chamando (executando) a função
    return 0;
}
Slide 07

Uma prévia: parâmetro e retorno

Só uma espiadinha

Os detalhes de como passar valores e devolver resultados a gente estuda com calma na Aula 9. Por hoje, só repare que existe.

dobro.c
#include <stdio.h>

// Prévia: função com 1 parâmetro e 1 retorno
int dobro(int numero) {
    return numero * 2;
}

int main() {
    int resultado = dobro(5);
    printf("%d\n", resultado);  // imprime 10
    return 0;
}

Slide 08

Uma vez escrita, chamada quantas vezes precisar

Da definição às chamadas
flowchart LR D["Definição da função (escrita 1 vez)"] --> C1["Chamada dentro do main()"] D --> C2["Chamada em outra função"] D --> C3["Chamada de novo, quando precisar"]

Reuso de verdade

A função é ESCRITA uma única vez. Mas pode ser CHAMADA (executada) várias vezes, de vários lugares do programa. É exatamente isso que resolve o problema do copiar e colar lá do começo da aula.

Slide 09

Onde colocar a função no arquivo

Se a função é definida ANTES do main, o compilador já a conhece quando chega lá. Se você prefere manter o main no topo do arquivo, declare um protótipo — só a "assinatura" da função, terminada em ; — antes do main, e escreva o corpo completo depois.

prototipo.c
#include <stdio.h>

void saudar();   // protótipo: avisa que a função existe

int main() {
    saudar();    // chamada - pode vir antes da definição completa
    return 0;
}

// definição completa, pode vir depois do main
void saudar() {
    printf("Bem-vindo ao programa!\n");
}

Exemplo prático

Transformando a tabuada numa função

Slide 10

A tabuada da Aula 5, agora reutilizável

tabuada.c
#include <stdio.h>

// Função que imprime a tabuada de um número
void imprimirTabuada(int numero) {
    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", numero, i, numero * i);
    }
}

int main() {
    imprimirTabuada(2);   // tabuada do 2
    imprimirTabuada(5);   // tabuada do 5
    imprimirTabuada(7);   // tabuada do 7

    return 0;
}

Sem a função, seria...

...copiar o for da Aula 5 três vezes (ou mudar o número na mão e recompilar toda hora). O parâmetro numero aqui é só uma prévia — a gente destrincha isso na Aula 9.

Exercícios: pratique com funções

  1. Escreva uma função void linha() que imprime uma linha de tracinhos e chame-a 3 vezes dentro do main, separando três blocos de texto diferentes.
  2. Pegue o cálculo de média com acumulador da Aula 2 e transforme em uma função void calcularMedia() — por enquanto sem parâmetro, só movendo o código de dentro do main pra dentro da função.
  3. Em uma frase, explique pra um colega a diferença entre DECLARAR uma função e CHAMAR uma função.
  4. Desafio: crie duas funções void diferentes (por exemplo saudarManha() e saudarNoite()) e use um if/else no main pra chamar a certa, dependendo de um horário digitado pelo usuário.

Dica de ouro

Compile e teste depois de escrever CADA função. É bem mais fácil achar um erro numa função pequena do que garimpar um programa inteiro de uma vez.
