Slide 02

Relembrando o while

// Sintaxe do while — testa a condicao ANTES de rodar
while (condicao) {
    // repete enquanto a condicao for verdadeira
}

Lembrete relâmpago (Aula 1)

O while testa a condição antes de rodar o bloco — se ela já começar falsa, o laço pode nunca executar nenhuma vez.

Slide 03

Relembrando o do-while

// Sintaxe do do-while — testa a condicao DEPOIS de rodar
do {
    // roda pelo menos uma vez, sempre
} while (condicao); // nao esqueca do ;

Lembrete relâmpago (Aula 3)

O do-while roda o bloco pelo menos uma vez antes de checar a condição — ótimo pra menus e validação de entrada. Cuidado pra não esquecer o ; depois do while(condicao).

Um Truque Novo: Limpando a Tela

Só um conceito novo hoje — e ele deixa seus menus muito mais organizados

Slide 04

system(): chamando o sistema operacional

Existe uma função em C chamada system() que executa, de dentro do seu programa, um comando do próprio sistema operacional — como se você tivesse digitado ele no terminal.

Cada sistema tem seu próprio comando de limpar tela
Sistema OperacionalComando em C
Windowssystem("cls")
Linux / Macsystem("clear")

O problema

Se você usar só system("cls"), o programa quebra num Linux/Mac. E vice-versa. Precisamos de um jeito de escolher o comando certo na hora de compilar.

Slide 05

Receita pronta: #ifdef _WIN32

limpar_tela.c
#ifdef _WIN32
    system("cls");
#else
    system("clear");
#endif

Pra que serve isso?

_WIN32 é uma macro que o compilador já reconhece automaticamente no Windows. Essa receita é perfeita pra usar dentro de um do-while de menu: a cada volta, a tela é limpa e o histórico de opções anteriores some, deixando o programa mais organizado.

20 Exercícios de Revisão

Metade while, metade do-while, crescendo em dificuldade — bora

Desafios

Exercícios de Revisão — Parte 1/4

  1. Use um while para imprimir os números de 1 a 10.
  2. Use um while para imprimir os números de 10 a 1, em ordem decrescente.
  3. Use um while para somar os números de 1 a 100 (acumulador) e mostrar o total.
  4. Use um while para contar quantos números pares existem entre 1 e 50 (contador).
  5. Peça números ao usuário com while, um de cada vez, até ele digitar 0 — some todos (acumulador) e mostre o total no final.
Desafios

Exercícios de Revisão — Parte 2/4

  1. Use um do-while para pedir uma senha até o usuário acertar (senha fixa no código, tipo "1234").
  2. Use um do-while para simular um menu com 3 opções + Sair, repetindo até "Sair" ser escolhida — por enquanto cada opção só imprime "Você escolheu a opção X".
  3. Refaça o exercício anterior, mas agora limpando a tela (system("cls")/system("clear") com #ifdef _WIN32) toda vez que o menu voltar a aparecer.
  4. Use um while para calcular o fatorial de um número digitado pelo usuário.
  5. Use um do-while para pedir números até o usuário digitar um número negativo, contando (contador) quantos números positivos foram digitados.
Desafios

Exercícios de Revisão — Parte 3/4

  1. Use um while para encontrar o maior número de uma sequência digitada pelo usuário (termina quando ele digitar -1).
  2. Use um do-while para exibir a tabuada completa (1 a 10) de um número escolhido pelo usuário.
  3. Faça uma contagem regressiva de 10 até 0 usando while, com uma mensagem de "Lançamento!" no final.
  4. Use um do-while para validar que o usuário digite um número entre 1 e 100, repetindo enquanto o valor estiver fora da faixa.
  5. Some apenas os números ímpares de 1 a 50 usando while (acumulador com uma decisão dentro do laço).
Desafios

Exercícios de Revisão — Parte 4/4

  1. Use um do-while para simular um caixa eletrônico simplificado: menu com "Consultar saldo" e "Sair", repetindo até sair e limpando a tela a cada volta ao menu.
  2. Calcule a média de N notas digitadas pelo usuário, onde N também é digitado no início, usando while como controle de quantas vezes repetir.
  3. Use um while para inverter os dígitos de um número digitado pelo usuário (ex: 123 vira 321) — dica: use o resto da divisão por 10 (% 10) e a divisão inteira (/ 10) repetidamente.
  4. Monte um menu com do-while com pelo menos 4 opções reais (soma, subtração, multiplicação e divisão de dois números digitados, além de Sair), limpando a tela toda vez que voltar ao menu.
  5. Desafio final — Jogo de Adivinhação: o programa "pensa" num número fixo escondido no código (ex: 7); o jogador digita palpites num do-while até acertar, contando (contador) quantas tentativas usou; ao acertar, limpe a tela e mostre um resumo final com o número de tentativas.
