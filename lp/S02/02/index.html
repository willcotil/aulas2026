Contadores

Contando quantas vezes algo aconteceu

Slide 02

O Que é um Contador?

int contador = 1;

while (contador <= 5) {
    printf("Repeticao numero %d\n", contador);
    contador++;
}

Já vimos isso disfarçado

Lembra da variável aura na aula passada, que crescia sempre de 20 em 20? Aquilo já era um contador. Um contador é uma variável que muda sempre pelo mesmo valor a cada volta do laço — serve pra saber quantas vezes algo aconteceu.

Slide 03

Contando Ocorrências

int numero = 1;
int pares = 0;

while (numero <= 20) {
    if (numero % 2 == 0) {
        pares++;
    }
    numero++;
}

printf("Quantidade de pares: %d\n", pares);

Repare que numero e pares são dois contadores diferentes: numero só controla o laço (de 1 a 20), enquanto pares conta quantas vezes a condição do if foi verdadeira. Nem todo contador precisa ser a variável que controla o while.

Acumuladores

Somando valores ao longo do laço

Slide 04

O Que é um Acumulador?

int quantidade = 3;
int contador = 1;
int soma = 0;
int valor;

while (contador <= quantidade) {
    printf("Digite um numero: ");
    scanf("%d", &valor);
    soma = soma + valor;
    contador++;
}

printf("Soma total: %d\n", soma);

Diferente do contador, soma não cresce sempre pelo mesmo valor — ela cresce pelo que o usuário digitou em cada volta. Uma variável que vai acumulando um total assim (soma, produto, etc.) se chama acumulador.

Slide 05

Contador vs Acumulador

Contador

Muda sempre pelo mesmo valor a cada volta (contador++, contador += 1). Serve pra saber quantas vezes algo aconteceu.

Acumulador

Muda por um valor diferente a cada volta, dependendo dos dados (soma = soma + valor). Serve pra somar/juntar algo ao longo do laço.

Slide 06

Vendo os Dois Crescerem

Contador (passo fixo) vs Acumulador (passo variável)
O contador sobe sempre do mesmo jeito, em degraus iguais. O acumulador sobe em saltos diferentes, dependendo do valor somado em cada volta.
Slide 07

Juntando os Dois: Calculando uma Média

int quantidade = 4;
int contador = 1;
int soma = 0;
int nota;

while (contador <= quantidade) {
    printf("Digite a nota %d: ", contador);
    scanf("%d", &nota);
    soma = soma + nota;
    contador++;
}

printf("Media: %d\n", soma / quantidade);

Os dois padrões, juntos

contador controla quantas notas já foram digitadas (e quando parar), enquanto soma acumula o total pra depois dividir pela quantidade. Praticamente todo problema de "calcular uma média" usa essa dupla.

Praticando com Contadores e Acumuladores

  1. Escreva um programa que conte quantos múltiplos de 3 existem entre 1 e 30, usando um contador de ocorrências separado do índice do laço.
  2. Escreva um programa que leia 5 números digitados pelo usuário e acumule a soma deles, imprimindo o total no final.
  3. Modifique o programa anterior para também calcular e imprimir a média dos 5 números.
  4. Escreva um programa que leia notas até o usuário digitar -1 (uma sentinela), contando quantas notas foram válidas e somando o total (dica: pense em como o while vai saber quando parar).
  5. Desafio: no código int soma = 0; int contador = 1; while (contador <= 5) { soma = contador; contador++; }, o programador queria acumular a soma de 1 a 5, mas cometeu um erro de digitação. Encontre e corrija.
  6. Escreva um programa que leia números até o usuário digitar 0, contando quantos são positivos e quantos são negativos, usando dois contadores diferentes.
  7. Escreva um programa que calcule o produtório (multiplicação acumulada) dos números de 1 até N — repare que esse acumulador precisa começar em 1, não em 0.
  8. Escreva um programa que leia o preço de itens digitados pelo usuário até ele digitar 0, acumulando o total da compra e contando quantos itens foram comprados.
  9. Desafio: um professor quer saber, numa turma de tamanho desconhecido, quantos alunos tiraram nota maior ou igual a 7 (use uma sentinela -1 pra parar). Conte também o total de alunos e calcule a média geral da turma.
  10. Escreva um programa que conte quantas vogais existem numa string (vetor de char), percorrendo-a com while até encontrar o \0 — retomando o conceito de string da Aula 1.
  11. Desafio: no código int cont = 0; int soma = 0; while (cont < 5) { scanf("%d", &valor); soma = soma + valor; }, existe um bug que causa laço infinito. Identifique e corrija.
  12. Desafio final: leia números digitados pelo usuário até ele digitar -1, e ao final imprima a soma, a quantidade de números lidos e a média — tudo com um único laço while e as variáveis certas de contador/acumulador.
