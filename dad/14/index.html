Fase 1: Menus Nativos

Saindo do HTML, entrando no Windows

Slide 03

O Que é o Menu Nativo?

Sabe aquela barra lá no topo dos programas com "Arquivo", "Editar", "Exibir" e "Ajuda"? Isso não é feito com HTML.

É o próprio Windows (ou Mac/Linux) que desenha aquela barra usando os componentes visuais padrão do sistema operacional.

Fica no Main.js

Como isso faz parte do Sistema Operacional, o HTML (Renderer) não tem poder para criar. Nós temos que mandar o Node.js (Main Process) desenhar esse menu para nós.

Vantagem: Atalhos

Menus nativos são a melhor forma de criar atalhos de teclado globais no seu app, como Ctrl + S para salvar ou Ctrl + Q para sair.

Slide 04

A Receita do Menu (Template)

Para o Electron construir um menu, nós só precisamos entregar a ele um Array de Objetos. Cada objeto é um "botão" do menu.

Exemplo Teórico (Array de Menu)
const modeloDoMenu = [
  // Primeiro Botão Principal
  {
    label: 'Arquivo',
    submenu: [
      { label: 'Novo Produto', click: () => console.log("Clicou!") },
      { type: 'separator' }, // Cria uma linha de divisão
      { label: 'Sair', role: 'quit', accelerator: 'Ctrl+Q' }
    ]
  },
  // Segundo Botão Principal
  {
    label: 'Ajuda',
    submenu: [
      { label: 'Sobre o Sistema' }
    ]
  }
];

Fase 2: A Bandeja

A famosa "System Tray"

Slide 06

O Que é a Bandeja (Tray)?

A Bandeja do Sistema é aquela área escondida no canto inferior direito do Windows, perto do relógio.

Por que usar o Tray?

Aplicativos como Discord, Spotify ou Antivírus precisam rodar em segundo plano o tempo todo para ouvir notificações. Se você deixar a janela deles aberta, polui a barra de tarefas. Mandar o app para a bandeja resolve esse problema!

Para usar isso no Electron, usamos o módulo Tray. Ele exige apenas uma imagem de ícone (`.png` ou `.ico`) para aparecer lá embaixo.

Slide 07

Fechado ou Escondido?

Quando o usuário clica no "X" vermelho do Windows, geralmente o app fecha de vez (morre). O truque do Tray é cancelar esse fechamento e apenas esconder a janela.

Fase 3: Mãos no Teclado

Construindo o Menu e o Ícone Juntos

Slide 09

A Nossa Missão em 3 Etapas

Abram o código da aula passada (O código do aula13.zip). Nós vamos continuar daquele exato ponto. Tudo o que faremos hoje é no arquivo index.js!

  • Etapa 1: O Menu Superior Nativo
    Vamos criar a receita do menu (Template), importar a classe Menu do Electron e mandar aplicar na janela.
  • Etapa 2: Preparando o Ícone do Tray
    Vamos precisar de uma imagem para o ícone e da classe Tray.
  • Etapa 3: O Menu do Botão Direito
    Ao clicar com o botão direito no ícone pequenininho da bandeja, queremos que um menu de contexto abra com as opções de "Abrir Janela" e "Sair de Vez".
Etapa 1

Criando o Menu da Janela Parte 1/3

Vá no seu index.js (O Cérebro). Logo na primeira linha, adicione o Menu à lista de ferramentas do Electron.

src/main/index.js (Lá no topo)
const { app, BrowserWindow, ipcMain, Menu } = require('electron');

Agora, dentro do bloco app.whenReady().then(() => { ... }), logo após criar a janela principal, cole o código do menu:

src/main/index.js (Dentro do whenReady)
// 1. A Receita do Menu
const templateDoMenu = [
    {
        label: 'Ações do Sistema',
        submenu: [
            { label: 'Mostrar Aviso', click: () => console.log("Aviso Clicado!") },
            { type: 'separator' },
            { label: 'Sair Imediatamente', role: 'quit', accelerator: 'CmdOrCtrl+Q' }
        ]
    }
];

// 2. Transforma a receita em um Menu de verdade
const menuReal = Menu.buildFromTemplate(templateDoMenu);

// 3. Aplica o menu à nossa aplicação inteira!
Menu.setApplicationMenu(menuReal);

Rodem npm start e vejam se a barra de cima mudou!

Etapa 2

A Imagem da Bandeja Parte 2/3

Antes de codificar o Tray, precisamos de um ícone. O Electron precisa do caminho de uma imagem no seu computador.

Onde colocar a imagem?

1. Vá ao Google e pesquise um ícone pequeno qualquer (procure por icon png 32x32).

2. Salve essa imagem dentro da pasta src/main/ do seu projeto com o nome icone.png.

Agora, na primeira linha do seu index.js, adicione também o Tray e declare a variável global:

src/main/index.js (No topo)
const { app, BrowserWindow, ipcMain, Menu, Tray } = require('electron');
const path = require('path');

let janelaPrincipal;
let tray = null; // A variável do ícone precisa ser global para não sumir!
Etapa 2

Criando o Ícone (Tray) Parte 2/3

Ainda dentro do app.whenReady().then(...), bem lá no final, mande o Electron ler a sua imagem e construir a bandeja.

src/main/index.js (Final do whenReady)
// ... (depois de aplicar o menu) ...

// O caminho da imagem que você baixou
const iconeCaminho = path.join(__dirname, 'icone.png');

// Cria o ícone no cantinho do relógio
tray = new Tray(iconeCaminho);

// Define a mensagem que aparece ao passar o mouse por cima
tray.setToolTip('Meu Super App rodando no fundo!');

Rodem npm start. Verifiquem perto do relógio do Windows se o seu ícone apareceu! (Pode estar escondido na setinha ^).

Etapa 3

O Menu da Bandeja (Context Menu) Parte 3/3

Se você clicar com o botão direito no ícone lá embaixo, nada acontece. Vamos criar um Menu de Contexto para ele!

A lógica é igualzinha a do menu superior: fazemos um Array, passamos pro Menu, e mandamos o tray usar.

src/main/index.js (Logo abaixo de criar o Tray)
const menuDoTray = Menu.buildFromTemplate([
    { 
        label: 'Abrir Painel', 
        click: () => {
            // Se a janela estiver escondida, mostre de novo!
            janelaPrincipal.show();
        } 
    },
    { type: 'separator' },
    { 
        label: 'Encerrar', 
        role: 'quit' // Função pronta do sistema
    }
]);

// Gruda esse menu no clique com o botão direito do ícone!
tray.setContextMenu(menuDoTray);
Teste Final

Testando a Máquina Inteira

1. Rode npm start.

2. Clique em "Arquivo" > "Esconder" no menu de cima (Se não criou, feche ou minimize a janela na mão).

3. Ache o seu ícone perto do relógio.

4. Clique com o botão direito nele e escolha "Abrir Painel" para reviver o seu app!

Desafios

Missões Extras (XP Adicional)

Agora que dominamos o Sistema Operacional, vamos brincar com atalhos e comportamento oculto.

  1. Novo Botão de Menu: Adicione uma nova aba principal no Menu Superior chamada "Visualizar". Dentro dela, coloque um botão "Recarregar" (Use a propriedade role: 'reload' ou um clique chamando janelaPrincipal.reload()).
  2. Comunicação Reversa: Crie um botão no Menu Superior chamado "Zerar Produtos". Quando o usuário clicar, em vez de dar console.log, faça o Menu executar um janelaPrincipal.webContents.send('zerar-tudo'). No seu arquivo `renderer.js`, crie um "ouvido" para esse canal que apague o HTML da tela.
  3. O Fechamento Falso: Geralmente, apps com Tray não fecham quando o usuário clica no 'X', eles apenas se escondem. Peça ajuda ao Google ou IA com o prompt: "No Electron, como interceptar o evento 'close' da BrowserWindow para cancelar o fechamento da janela usando `e.preventDefault()` e usar o método `hide()` para apenas esconder a tela?". Implemente isso!
  4. Desafio IA (Atalhos Globais): Um recurso poderoso é ativar funções mesmo quando o app está minimizado. Peça à IA: "Como usar o módulo 'globalShortcut' do Electron para registrar as teclas 'CommandOrControl+Shift+A' e fazer a minha janela abrir (show) não importa em qual tela o usuário esteja?".
