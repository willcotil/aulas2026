Slide 02

Por que abandonar o alert()?

Até agora, quando queríamos avisar algo ao usuário, usamos o velho alert("Produto adicionado!") do navegador. Ele funciona, mas...

Problemas do alert()

  • Visual feio e datado.
  • Só tem 1 botão ("OK").
  • Não combina com o sistema.
  • Travado dentro da janela do app.

Vantagens do dialog

  • Cara de Windows/Mac/Linux de verdade.
  • Múltiplos botões (Sim, Não, Cancelar...).
  • Ícones de aviso, erro, pergunta.
  • Bloqueia o app inteiro até responder.

O módulo dialog mora no Main Process (index.js) e abre janelas do sistema operacional!

Fase 1: MessageBox

O Canivete Suíço dos Diálogos

Slide 04

O showMessageBox

É o diálogo mais flexível. Serve para avisar, perguntar ou confirmar qualquer coisa. Você escolhe título, mensagem, ícone e até os botões!

Confirmação

Tem certeza que deseja remover o último produto?

Essa ação não pode ser desfeita.

☝️ Esse cara aí em cima é um showMessageBox nativo, não é HTML/CSS!

Slide 05

A Receita do MessageBox

O método dialog.showMessageBox() recebe um objeto de configurações. Cada propriedade controla uma parte da janela:

Exemplo Teórico
const { dialog } = require('electron');

const resposta = await dialog.showMessageBox({
    type: 'question',         // 'info', 'error', 'question', 'warning'
    title: 'Confirmação',
    message: 'Tem certeza?',
    detail: 'Detalhes extras em letra menor.',
    buttons: ['Sim, remover', 'Cancelar'],
    defaultId: 1,             // Botão pré-selecionado (índice)
    cancelId: 1               // Qual botão é o "Cancelar"
});

// resposta.response é o ÍNDICE do botão clicado (0, 1, 2...)
if (resposta.response === 0) {
    console.log("Usuário confirmou!");
}

Detalhe importante

O showMessageBox é assíncrono: ele devolve uma Promise. Por isso usamos await (ou .then()). Sem await, o resultado vem vazio!

Fase 2: ErrorBox

Quando dá ruim, dá ruim rápido!

Slide 07

O showErrorBox

É o irmão mais simples do MessageBox. Serve só para uma coisa: mostrar um erro feio com ícone vermelho. Não precisa de objeto, não tem botões, não devolve nada.

Erro

Arquivo Inválido

O arquivo selecionado não é um JSON válido.

A receita é simples!
dialog.showErrorBox(
    'Arquivo Inválido',
    'O arquivo selecionado não é um JSON válido.'
);

Só dois argumentos: título e mensagem. E é síncrono (sem await)!

Fase 3: OpenDialog

"Procurar arquivo..."

Slide 09

O showOpenDialog

Sabe quando você anexa um arquivo no WhatsApp Web ou abre um documento no Word? Aquela janelinha de selecionar arquivo é o que vamos invocar agora!

Exemplo Teórico
const resultado = await dialog.showOpenDialog({
    title: 'Selecione o arquivo de produtos',
    properties: ['openFile'],   // 'openDirectory', 'multiSelections'...
    filters: [
        { name: 'Arquivos JSON', extensions: ['json'] },
        { name: 'Todos os Arquivos', extensions: ['*'] }
    ]
});

// resultado é um objeto:
//   resultado.canceled  -> true se clicou em "Cancelar"
//   resultado.filePaths -> array com os caminhos selecionados

if (!resultado.canceled) {
    console.log("Arquivo escolhido:", resultado.filePaths[0]);
}

Os Filtros

A propriedade filters é o que faz aparecer aquele dropdown "Arquivos JSON (*.json)" no canto da janela. Ela não impede o usuário de selecionar outro tipo de arquivo, só ajuda a esconder os irrelevantes.

Fase 4: SaveDialog

"Salvar como..."

Slide 11

O showSaveDialog

Praticamente idêntico ao OpenDialog, mas em vez de escolher um arquivo existente, o usuário nomeia um novo arquivo e escolhe onde salvar.

Exemplo Teórico
const resultado = await dialog.showSaveDialog({
    title: 'Salvar lista de produtos',
    defaultPath: 'produtos.json',   // Nome sugerido
    filters: [
        { name: 'Arquivos JSON', extensions: ['json'] }
    ]
});

// resultado.canceled  -> true se cancelou
// resultado.filePath  -> O caminho que o usuário ESCOLHEU
// ⚠️ Atenção: filePath (singular!) e não filePaths!

if (!resultado.canceled) {
    console.log("Vai salvar em:", resultado.filePath);
}

⚠️ Atenção! O SaveDialog não salva nada por si só. Ele só te devolve o caminho escolhido. Quem grava o arquivo seria o módulo fs (que veremos no futuro).

Etapa 1

Preparando o Terreno Parte 1/4

Primeiro, você precisa importar o módulo dialog do Electron. Abra seu index.js e procure a linha das importações (lá no topo):

src/main/index.js (Topo - ANTES)
const { app, BrowserWindow, ipcMain, Menu, Tray } = require('electron');

Adicione dialog à lista!

src/main/index.js (Topo - DEPOIS)
const { app, BrowserWindow, ipcMain, Menu, Tray, dialog } = require('electron');

Ajuste importante na função do menu!

Nossa função criarMenuPrincipal() hoje não recebe nada. Mas agora vamos precisar mandar mensagens para a janela principal, então ela precisa receber a janela como parâmetro:

src/main/index.js (Modificações)
// Lá no whenReady, mude a chamada:
criarMenuPrincipal(janelaPrincipal);  // Passa a janela!
criarTray(janelaPrincipal);

// E a assinatura da função lá embaixo:
const criarMenuPrincipal = (janela) => {  // Recebe a janela
    const templateDoMenu = [
        // ... (o menu "Ações do Sistema" continua igual) ...
    ];
    // ... resto igual
}

Agora dentro do template do menu, conseguimos acessar a variável janela e o array db (que também está acessível porque está no topo do arquivo).

Etapa 2

Confirmação Antes do Pop Parte 2/4

Vamos preencher o click do botão "Remover Último Produto". A ideia: perguntar antes de remover o último item do array db.

src/main/index.js (Dentro do click do Remover)
click: async () => {
    // 1. Mostra o diálogo de confirmação
    const resposta = await dialog.showMessageBox({
        type: 'warning',
        title: 'Remover Produto',
        message: 'Tem certeza que deseja remover o último produto?',
        detail: `Vai sumir: "${db[db.length - 1].nome}"`,
        buttons: ['Sim, remover', 'Cancelar'],
        defaultId: 1,
        cancelId: 1
    });

    // 2. Decide com base no índice do botão clicado
    if (resposta.response === 0) {
        db.pop(); // Remove do array em memória
        janela.webContents.send('atualizar-tela');
    }
}

Reutilizando o que já temos!

Olha que legal: o seu renderer.js já tem um ouvinte onAtualizarTela() que chama iniciarApp() — exatamente o que precisamos! Quando o Main mandar o sinal, a tela vai buscar a lista nova sozinha. Reaproveitamento puro!

Etapa 3

Importando do JSON Parte 3/4

Aqui vamos abrir um JSON do disco usando o showOpenDialog. O diálogo vai aparecer e deixar o usuário escolher um arquivo.

src/main/index.js (Dentro do click do Importar)
click: async () => {
    // 1. Abre o seletor de arquivos
    const resultado = await dialog.showOpenDialog({
        title: 'Escolha um arquivo JSON de produtos',
        properties: ['openFile'],
        filters: [{ name: 'JSON', extensions: ['json'] }]
    });

    // 2. Se cancelou, sai fora
    if (resultado.canceled) return;

    // 3. Aqui é onde vamos ler e processar o arquivo!
    const caminhoEscolhido = resultado.filePaths[0];

    // Mostra um aviso ao usuário
    dialog.showMessageBox({
        type: 'info',
        title: 'OpenDialog Funcionando!',
        message: 'Arquivo selecionado:',
        detail: `${caminhoEscolhido}\n\nNo próximo semestre, vamos aprender a ler e processar esse arquivo com o módulo fs (File System).`
    });
}

Ponte para o futuro

Você acaba de fazer a primeira metade do processo de importação: perguntar ao usuário qual arquivo. A segunda metade — ler o conteúdo, validar se é JSON, adicionar ao array — será abordada no próximo semestre quando estudarmos o módulo fs e tratamento de erros com try/catch.

Etapa 4

O Caminho de Salvamento Parte 4/4

Como ainda não dominamos a escrita de arquivos, vamos só demonstrar o SaveDialog capturando o caminho escolhido pelo usuário e mostrando num MessageBox:

src/main/index.js (Dentro do click do Exportar)
click: async () => {
    // 1. Pergunta ao usuário onde salvaria
    const resultado = await dialog.showSaveDialog({
        title: 'Exportar lista de produtos',
        defaultPath: 'minha-lista-de-produtos.json',
        filters: [{ name: 'JSON', extensions: ['json'] }]
    });

    if (resultado.canceled) return;

    // 2. Mostra o caminho num diálogo (só pra ver funcionando)
    await dialog.showMessageBox({
        type: 'info',
        title: 'Caminho Capturado',
        message: 'Aqui é onde salvaríamos o arquivo:',
        detail: `${resultado.filePath}\n\nNa próxima aula, vamos aprender a gravar de verdade com o módulo fs.writeFile!`
    });
}

Ponte para a próxima aula

Você acabou de fazer o "meio caminho" do salvamento: perguntar onde. Falta só o como gravar, que veremos no estudo do módulo fs (File System).
